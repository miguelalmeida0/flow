# Install

Requires Node.js 22 or newer.

```bash
cd ~/Downloads/flow-voice-calendar
npm install
npm run dev
```

If you previously extracted an older broken archive, remove it first and extract the new archive again.

```bash
cd ~/Downloads
rm -rf flow-voice-calendar
unzip flow-voice-calendar-production-fixed.zip
cd flow-voice-calendar
npm install
npm run dev
```
