# 11 — Scope and Non-Goals

## P0

- shared living shell;
- real Home projections;
- existing Calendar/Tide integration;
- Inbox capture and resolution;
- Plan list/detail;
- Inbox → Plan atomic morph;
- Plan step → Calendar link;
- People commitments;
- deterministic Now recommendations;
- global command dock;
- voice navigation and synthetic voice path;
- local persistence and global undo/redo;
- mobile and reduced motion.

## P1

- persistent Flow Live session;
- polished shared transitions;
- cross-space lineage details;
- motion/performance hardening;
- physical microphone acceptance where supported.

## Explicit non-goals

Do not add in this release:

- Three.js;
- WebGL/GLSL;
- canvas-only UI;
- image generation;
- animated avatars;
- a chatbot transcript;
- provider calendar sync;
- Gmail/Slack/WhatsApp integration;
- accounts, cloud sync, or multiplayer;
- payment or subscription system;
- contact import or CRM;
- money/banking features;
- household module;
- native background wake word;
- multilingual free-form NLP;
- a general-purpose LLM dependency;
- social feed;
- badges, streaks, points, or childish gamification;
- a broad project-management suite;
- month/year calendar redesign;
- speculative 3D effects.

## Product discipline

The app should feel bigger because its parts share meaning, not because it has more navigation items.

A beautiful screen that does not share real state is a prototype defect.

A beautiful animation that can corrupt, duplicate, or hide data is a release blocker.
