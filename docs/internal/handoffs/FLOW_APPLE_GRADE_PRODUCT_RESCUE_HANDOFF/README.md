## Assets

`assets/current-state/` contains screenshots of the current broken product state. Treat them as failure evidence, not visual targets.

`assets/target/` contains visual references for the intended dark Flow atmosphere. Treat them as direction, not pixel-perfect requirements. Utility and coherent behavior take priority over static resemblance.

## Required outcome

A user starts one Live Session and can complete a cross-space journey without clicking the microphone again:

- navigate between Home, Today, Capture, Outcomes, and Commitments;
- create and edit calendar events from any space;
- capture ideas without misrouting navigation commands;
- create outcomes, add a next step, and schedule it;
- create commitments linked to people and dates;
- ask what needs attention now;
- use contextual follow-ups such as “make it red”;
- undo and redo globally.

The product is not release-ready until that journey works through a physical microphone and the automated release gates are green.
